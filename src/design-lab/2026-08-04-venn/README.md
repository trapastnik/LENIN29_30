# Диаграмма Венна — перераскладка под 33 партии

**Дата:** 2026-08-04 · **Зона:** `design` · **Подключает:** `ui`

Заявка оркестратора: чипов станет 33 вместо 15, при нынешней раскладке они
почти касаются, и цель — развести хит-зоны так, чтобы 64 px не перехватывали
соседа.

Задача оказалась шире. Ниже — почему, и что с этим сделано.

## Три находки, меняющие объём

**1. Координат чипов в проекте нет.** В `parties/_index.json` есть только
`venn_headers` — пять позиций подписей групп. Кураторских `x`/`y` из M0,
о которых шла речь, в индексе не осталось: пересчитывать нечего, раскладка
считается с нуля.

**2. `venn-bg.png` не вмещает данные.** Красный блоб слева вверху, жёлтый
справа внизу — они не пересекаются вообще, а данным нужно `national ∩ red`
на три партии (Мусульманские социалистические комитеты, Боротьбисты, СДП
Финляндии). Так же нет `national ∩ white` (Алаш) и практически нет
`green ∩ national` (Басмачество). **Три требуемые области из шести
физически отсутствуют на картинке.**

**3. Растр не разбирается алгоритмом — в принципе.** Пробовал три способа
восстановить области по пикселям, все вырождаются по одной причине: вклад
`national` в цвет `(71, 44, −10)` почти равен сумме вкладов `red`
`(68, −1, −7)` и `green` `(−1, 28, 0)`. «Национальные» и «красные ∩ зелёные»
дают неотличимый пиксель. Это свойство самой картинки, а не разбора:
подогнать чипы под неё нельзя даже теоретически.

Отсюда решение: **геометрия строится из данных**, растр заменяется вектором.

## Что требуют данные

33 партии, 5 групп, 12 пересечений — всё из `venn_groups`.

| Область | Чипов | | Область | Чипов |
|---|---|---|---|---|
| `national ∩ rev-dem` | 4 | | `red` | 2 |
| `national ∩ red` | 3 | | `rev-dem` | 7 |
| `rev-dem ∩ white` | 2 | | `white` | 5 |
| `red ∩ rev-dem` | 1 | | `green` | 2 |
| `national ∩ white` | 1 | | `national` | 5 |
| `green ∩ national` | 1 | | | |

`national` — узел степени 4 (связан с `red`, `rev-dem`, `white`, `green`),
`rev-dem` — степени 3. Это и задаёт компоновку.

**Запрещённых пар четыре:** `red–white`, `red–green`, `rev-dem–green`,
`white–green`. Их появление — такая же ошибка, как отсутствие нужной:
посетитель прочтёт связь, которой в данных нет.

**Тройных областей не должно быть ни одной.** В данных нет партий с тремя
группами, а пустая тройная область на диаграмме читается как «сюда просто
никого не положили».

## Как считалось

`scripts/venn_solve.py` — подбор геометрии. Пять блобов-суперэллипсов
с органической модуляцией радиуса; 30 параметров, поэтому не руками,
а восхождением со случайными рестартами и явными штрафами:

- существуют ровно шесть парных областей из данных;
- ни одной лишней парной, ни одной тройной;
- у каждой области хватает **полезной** площади на свои чипы.

«Полезная» — после отступа 46 px от края области. Это не придирка: без
эрозии четвёртый чип в узкой линзе `national ∩ rev-dem` не влезал, а чип,
свисающий за край, визуально попадает в чужую группу.

`scripts/venn_place.py` — расстановка. Жадно, от самой удалённой точки,
с проверкой минимального расстояния до всех уже поставленных.

`scripts/venn_probe.py` — разбор старого PNG, которым получена находка 3.

## Результат

```
штраф 0 — все 11 областей проходят по площади
лишних пар нет, тройных нет
размещено 33 из 33
минимальное расстояние между центрами 118 px при требовании 64
на киоске (--ui-scale: 2) — 236 px
```

Запас почти двукратный, то есть чипам есть куда расти: подпись длиннее
или кегль крупнее не сломают раскладку.

## Файлы

| | |
|---|---|
| `venn-layout.svg` | превью: блобы, чипы, окружности хит-зон |
| `venn-blobs.json` | пять фигур: `[cx, cy, rx, ry, поворот, фаза]` |
| `venn-chips.json` | 33 чипа с `x`/`y` в процентах кадра |
| `scripts/` | генератор, расстановщик, разбор старого PNG |

Кадр — 1920×1080 логических, `venn_aspect` 16/9 сохранён. Координаты
в процентах, поэтому `venn-selector.js` их принимает без правок:
он уже ставит `chip.style.left = it.x + '%'`.

## Что нужно от зон

**`content`** — положить `x`/`y` в `items` у `parties/_index.json`.
Ручная правка сгенерированного json запрещена (§9), значит либо в скрипт
импорта, либо в `.patch.json`. Значения — из `venn-chips.json`.

**`ui`** — заменить растровый фон вектором и убрать `venn-bg.png` (1.4 МБ)
из сборки. Заодно `venn-selector.js:289` пишет `var(--camp-${camp}, #888)` —
это R2, запас у цвета: неизвестный лагерь станет серым вместо того, чтобы
упасть заметно. Все `--camp-*` существуют, запас можно убрать.

## Чего здесь нет

Формы блобов подобраны под топологию, а не нарисованы художником.
Силуэт живой, но это инженерное решение задачи «где что лежит», а не
готовая графика. Если заказчик утверждал именно ту картинку — переигрывать
надо не раскладку, а данные: три пересечения из двенадцати на старом фоне
положить некуда.
