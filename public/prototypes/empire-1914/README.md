# Российская империя — 1914

Автономный просмотрщик векторной карты Российской империи (издание 2023/Sharada, отражает административно-территориальное деление на 1914 г.; для МТК 29 берётся как базовая «довоенная» подложка перед материалом по 1917-1922).

Открывать напрямую:

```text
prototypes/empire-1914/index.html
```

## Что внутри

- Полноразмерный SVG с именованными слоями Adobe Illustrator (Ocean, PROVINCE, RIVER, Railway, Capital, Guberniya Boundary и т. д.).
- Сайдбар с группировкой слоёв по категориям: Адм. единицы / Границы и сетка / Гидрография / Транспорт / Населённые пункты / Подписи и легенда / Прочее.
- Чекбоксы on/off для каждого слоя + счётчик графических объектов в скобках.
- Фильтр по имени слоя.
- Кнопки `Все` / `Ничего` / `Сброс`.
- Pan / zoom мышью (колесо — зум вокруг курсора, drag — панорама, dblclick — сброс вида).

## Технические заметки

- Слои читаются динамически из SVG: скрипт спускается внутрь `<switch><g i:extraneous="self">…</g></switch>` (обёртка Illustrator) и берёт оттуда прямых детей `<g id="…">`.
- Имена идентификаторов прогоняются через `_xNN_` → символ, чтобы из `_x31_3_2_` получить `13_2` и т. п.
- ViewBox-pan/zoom правит `viewBox` SVG, без CSS-transform — линии остаются хрусткими на любых масштабах.
- SVG ~11 МБ, отдаётся «как есть»; никаких пре-процессоров.
