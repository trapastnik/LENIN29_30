## Линтер `scripts/design/brand-lint.mjs`

Node без зависимостей. Восемь правил:

| # | Правило | Уровень |
|---|---|---|
| R1 | сырой hex вне `tokens.json` и allowlist | error |
| R2 | `var(--x, #hex)` — fallback это скрытая вторая палитра | error |
| R3 | italic там, где семейство резолвится в Nolde/`--font-display` | error |
| R4 | `var(--x)` для несуществующего токена | error |
| R5 | `:hover` вне `public/prototypes/**` | error |

**R2 не формальность.** В `map-unit.js:39` стоит `var(--brass, #8e6a2a)`
при реальном `--brass = #D2B773` — fallback молча включается при опечатке
в имени токена.

**R4 ловит реальную проблему:** `--ochre`, `--paper-light`, `--paper-warm`,
`--wood` используются на 6 страницах и в `map-unit.js`, но **не определены
нигде**. Эти страницы сейчас рендерятся с унаследованным цветом.

**R3 — 27 нарушений.** Курсив на Nolde запрещён (файла начертания нет,
браузер синтезирует наклон — на крупных кеглях видно как дефект засечек).
Самые заметные: `brand.html:1166` (280px), `brand.html:1187` (150px),
`direction-b.jsx:312` (180px), `shared.jsx:154` (год 210px),
`direction-a.jsx:1103` (92px). Курсив 20 Kopeek и 21 Cent **легален** —
файлы подключены в `fonts.css`, правило только про Nolde.

Замена наклона на разрешённые средства акцента: трекинг, латунный цвет,
слэш-метка, капитель, наклонный параллелограмм (главный мотив брендбука

исключений, вычёркивай по мере уборки.

## 4K

Решение dvn: **вёрстка в 1920×1080 логических, ×2 на киоске**.

```css
:root { --ui-scale: 1; --fs-body: calc(16px * var(--ui-scale)); }
@media (min-width: 2400px) { :root { --ui-scale: 2; } }   /* единственный media-query в проекте */
html { font-size: calc(16px * var(--ui-scale)); }
```

`/expo/` не трогать — его canvas 1920→3840 уже даёт ×2, численно совпадает.
`--force-device-scale-factor=2` **не ставить**: при DPR=2 `clientWidth`
станет 1920, `scale` вычислится как 1, растр отрисуется как 1× на физически
2× экране.

## `brand.html` — сделать источником правды на деле

Сейчас это второй по объёму источник хардкода в проекте (131 hex). Каталог,
который сам не следует правилам, источником правды быть не может.

1. Свотчи и все шкалы рендерятся **из токенов**, а не описывают их.
2. Каталог показывает отчёт линтера (`brand-lint --json`).
3. Стабильные якоря на блоках: `#c-spravka-card`, `#c-venn-chip`,
   `#c-territory-cell`, `#c-chronicle-row`. Тогда постановка задачи другим
   зонам — «свёрстай по `brand.html#c-spravka-card`», а не пересказ словами.
4. Раздел «Запрещено» с живыми примерами: курсив на Nolde рядом с правильным
   акцентом, hover рядом с `:active`, самодельная тень рядом с `--sh-2`.

Понадобятся новые блоки под предстоящий объём: карточка справки, чип Венна,
ячейка сетки территорий, строка ленты хроники, блок лонгрида, легенда карты,
состояния «загрузка / нет карты».
