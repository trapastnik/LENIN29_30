написать. Управление идёт через три вещи: файлы (`CLAUDE.md`,
`docs/launch/*.md`), git (ветки физически не дают затереть друг друга)
и dvn как канал связи. Чат доходит до ворот, говорит dvn, dvn говорит тебе,
ты идёшь смотреть ветку.

на ostrov fail2ban банит при серии частых попыток:

```bash

ssh ostrov 'cd /root/mtk29-src && git pull --ff-only && npm run build \
  && rsync -a --delete --exclude=nginx.conf --exclude=content/media/ dist/ /var/www/mtk29/ \
  && cp deploy/nginx.conf /var/www/mtk29/nginx.conf \
  && docker exec mtk29-web nginx -s reload'
```
