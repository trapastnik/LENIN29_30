## Цель проекта

**МТК 29 — «Россия в Гражданской войне»** — кинематографичная видео-проекция
для Государственного музея В.И. Ленина. Финальная поставка — **зацикленный
видеофайл** под музейный экран; интерактив (если будет) — только инструмент
авторинга.

Сценарий охватывает **1918–1922** на территории бывшей Российской империи:
фронты Гражданской войны, перемены столиц, государственные образования,
ключевые операции, персоналии.

**Парный** для МТК 30 (тоже видео-проекция, другой период / угол). 29 и 30
живут в одном репо `trapastnik/LENIN29_30` под общей кодовой базой.

## Что уже сделано (использовать как фундамент)

### 1. Калибровщик карт `empire-1914`
Полноценный SVG-просмотровщик / калибровщик. Положение:
`mtk29/public/prototypes/empire-1914/index.html`. Документация:
`mtk29/docs/HANDOFF-empire-1914.md`.

Готовые функции:
- Сменная подложка (любая SVG как фон, по умолчанию векторная карта Российской
  империи 1914)
- Калибровка наложений по контрольным точкам (affine LSQ + TPS warp)
- Автомэтч по подписям городов с RANSAC
- Ручная разметка через 🏙 city-tagger
- Snap-to-marker (учёт `*_Mark` слоёв)
- Per-layer toggle, перекраска monochrome потрейс-выходов

Это **инструмент препроцессинга** — выровненные overlay-карты идут в
`mtk29/public/content/maps/<имя>/layers.svg` для использования в финальной
проекции МТК 29.

Текущая ветка: `feature/swappable-background` (не смерджена). Файлы:
- viewer: `public/prototypes/empire-1914/index.html` (~2500 строк, self-contained)
- handoff калибровщика: `docs/HANDOFF-empire-1914.md`

## Подход к новому решению

Следуем МТК-24-паттерну с поправкой на масштаб и тип контента МТК 29:

1. **Прочитать `МТК 30 Сценарий.docx`** — извлечь временную шкалу, сцены,
   список объектов, дикторский текст. Сделать первый набросок
   `data/scenario.js` по образцу МТК 24.

2. **Определить «карту» для МТК 29.** В отличие от МТК 24 (один Петроград),
   здесь — вся бывшая Российская империя. Варианты:
   - Большая базовая карта 1914 + анимация фронтов поверх (через overlay'и
     откалиброванные в `empire-1914` калибраторе)
   - Серия региональных карт, переключение по сценарию
   - Гибрид: главный план — империя, региональные врезки — отдельные карты

   В любом случае — конвейер «откалибровать в `empire-1914` → сохранить в
   `content/maps/<имя>/layers.svg` → подключить в сцене» уже работает.

3. **Архитектура сцены.** Скорее всего:
   - `three.js` + vanilla JS, без бандлеров (как у 24)
   - `index.html` с раскладкой (рабочий экран + ГЗК + таймлайн)
   - `scene.js` — three.js-сцена: карта-фон, слои-overlay'и, объекты,
     эффекты, камера, тайминг
   - `data/scenario.js` — сценарий
   - `data/locations.js` — нормированные координаты объектов
   - `tools/authoring.html` — визуальный редактор (можно
     переиспользовать паттерн из МТК 24)

4. **Параллельные сессии — соблюдать зоны ответственности.** МТК 24
   разделил на «сцена/UI» и «модели». Скорее всего у нас тоже будут
   разные роли. Главное правило: **коммитить только свои файлы поимённо,
   НЕ `git add -A`**.
